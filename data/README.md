# Put the two recordings here

This folder is not part of the repository. Download the recordings (link in the
main README) and unpack them so that it looks like this:

```text
data/
├── Myroomesh1_imgs/       Myroomesh1_rawdata/       Myroomesh1_ply/
└── Myroomesh2_imgs/       Myroomesh2_rawdata/       Myroomesh2_ply/
```

Any two recordings in the same layout work; see [docs/data-format.md](../docs/data-format.md).
Check a folder before running with `navdelta check-data` (or `./run.sh check-data`).
